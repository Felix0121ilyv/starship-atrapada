# Atrapada doble de Starship

Simulación interactiva del Vuelo 15 de Starship: línea de tiempo del plan, motores encendidos en cada momento y la atrapada del booster y de la Ship por la torre.

Abrir `index.html` o visitar el sitio en GitHub Pages.

Tiempos T+ según el plan publicado; lo marcado «est.» es estimado. Alturas y velocidades son aproximadas.
